# LUMINA 创作台

从摄影知识出发，把画面想法变成图片或视频。

## 可以做什么

- 浏览构图、光影、色彩、光学、材质、运镜和风格，结合例图理解画面效果。
- 写下想法，获取推荐配料，调整后准备拍法并生成图片或视频。
- 保留每一版作品与设置，对照结果，继续修改创作。

## 开始创作

打开侧栏 LUMINA，填写画面想法，选择配料，然后进入创作详情准备拍法。生成图片或视频前，在「API 配置」中添加对应服务。

## 运镜动态演示

在运镜页点击「加载动态演示」，可批量下载 97 个 GIF（约 308 MB）。支持取消和重试，下载后缓存到本机，再次查看无需重复下载。只播放可见卡片，也可随时切回静态图。

## 费用说明

文字方案使用 DSH 的模型服务；图片和视频生成使用你配置的服务，可能产生费用。下载动态演示不调用生成模型。
